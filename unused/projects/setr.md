# Controlling a Robot using ArUco Marker as instructions

The goal of this project is to create a robot capable of following instructions given by a set of 6x6 ArUco markers which are described in the following table:

| Marker Id | Instruction |
| --------- | ----------- |
| 0 | Move forward |
| 1 | Move backwards |
| 2 | Move left | 
| 3 | Move right |
| 4 | Move in a circle forwards |
| 5 | Move in a circle backwards |
| 6 | Follow the marker |
